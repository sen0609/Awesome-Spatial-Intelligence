# Awesome Spatial Intelligence

**空间智能：研究图谱、关键技术与评测体系** 相关文献与研究图谱。

A curated companion reading list for *Spatial Intelligence: Research Landscape, Key Technologies, and Evaluation Frameworks*, organized by spatial capabilities and evaluation tasks.

本仓库围绕“**两层五环节**”组织空间智能研究：基础认知层包括**感知、表征、理解**，高阶能力层包括**推理、生成**；同时整理各环节的公开评测任务、基准与评价维度。重点关注三维几何、跨视角关系、动态空间状态与可交互世界模型。

## 组织方式

| 层次 | 能力环节 | 主要关注 |
| --- | --- | --- |
| 基础认知层 | 空间感知 | 观测、深度、几何恢复与视角选择 |
| 基础认知层 | 空间表征 | 几何基元、隐式场、语义结构与空间接口 |
| 基础认知层 | 空间理解 | 三维目标、分割、定位与场景图 |
| 高阶能力层 | 空间推理 | 度量、关系、视角、动态与组合推理 |
| 高阶能力层 | 空间生成 | 三维物体与场景、视频和世界模型 |
| 跨环节诊断 | 评测体系 | 任务、公开基准、指标与能力覆盖 |

CSV / JSON 中的主题标签依据文献在综述相关章节中的出现位置生成；同一作品可对应多个主题，不构成对作品全部能力的独立评定。

## 更新与核查

本仓库作为可持续维护的文献索引。后续将补充新的代表性研究，并持续复核 arXiv 条目的发表状态、题名、作者、年份与版本链接。有正式期刊或会议版本时，优先更新为正式发表版本，并保留必要的预印本关联，避免将同一工作的不同版本重复计入。

新增或更正条目时应提供论文题名及 DOI、arXiv、出版社、会议或作者项目页等来源链接，并说明所属环节或评测任务。欢迎通过 [Issues](https://github.com/sen0609/Awesome-Spatial-Intelligence/issues) 提交公开的文献建议与元数据更正。

当前参考文献导入自综述的实际文末显示清单，部分条目尚待进一步外部复核。缺失的 DOI 或链接保持空缺，不用猜测的信息补齐。未来检索将逐次记录查询日期、词组、实际查看范围、去重依据和筛选结果，见 [整理说明](SEARCH_PROTOCOL.md)。
